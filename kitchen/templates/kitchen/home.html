🧑‍🍳 What it is

What Is an Emoji Kitchen?

Emoji Kitchen is commonly associated with Google's emoji-mixing feature, which offers supported combinations through compatible Google products. Emoji Kitchen Hub is an independent website that provides its own browser-based emoji-mixing experience.

The results created by an emoji mixer are sticker-style images, not newly registered Unicode emoji characters.

The website also provides an online emoji keyboard, themed emoji collections and educational guides. Use the mixer to explore sticker-style mashups, or choose the keyboard when you need standard emoji characters for text. On a PC, the Windows Emoji Keyboard opens with a keyboard shortcut.

Using Emoji Mashups on Different Devices

The browser mixer on this website and Google's Emoji Kitchen feature are separate products, and their controls and available results can differ. Standard emojis can also look different across devices because each platform uses its own artwork.

Mobile Browsers

The mixer works in a mobile browser. Tap an emoji in each selection area and check whether a result appears.

Copying an image is not supported in every mobile browser or app. If pasting does not work, use Download, then attach the saved image through the destination app's image picker, where supported.

⌨️

Gboard and Google's Emoji Kitchen

Google's Emoji Kitchen is associated with supported Gboard experiences on Android. Open a compatible application, bring up Gboard and look for available emoji combination suggestions.

The exact experience can vary by device, application and software version. If the feature is unavailable, consult the relevant Gboard guide rather than assuming that Google's keyboard and this website's browser tool have identical controls.

If you need an ordinary emoji character inside a sentence, use the online emoji keyboard instead of a sticker-style image.
