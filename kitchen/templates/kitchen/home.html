🧑‍🍳 What it is

What Is an Emoji Kitchen?

Emoji Kitchen Hub is an independent website that helps visitors explore supported emoji combinations through a browser-based tool. It is separate from Google's Emoji Kitchen feature available through supported Google products.

The website also provides an online emoji keyboard, themed emoji collections and educational guides. Use the mixer to explore sticker-style mashups, or choose the keyboard when you need standard emoji characters for text.

Google first introduced the feature through Gboard on Android. It is also available through Google Search, giving more users a way to make combinations from a phone, tablet, or computer browser.

The results are sticker-style pictures, not new standard emojis. They may send as images inside messages, which helps the design stay clear across many apps and devices. For standard symbols, an emoji keyboard online works well. On a PC, the Windows Emoji Keyboard opens with a keyboard shortcut.

Use Google's Emoji Kitchen on Android

Google's Emoji Kitchen is associated with supported Gboard experiences on Android. Open a compatible application, bring up Gboard and look for available emoji combination suggestions.

The exact experience can vary by device, application and software version. If the feature is unavailable, consult the relevant Gboard guide rather than assuming that Google's keyboard and this website's browser tool have identical controls.

If you need an ordinary emoji character inside a sentence, use the online emoji keyboard instead of a sticker-style image.

ℹ️ Good to know

Understanding Emoji Mashups

The mixer works with supported emoji pairs, not every possible combination. The result is an image-style mashup rather than a new Unicode character.

Standard emojis may look different across devices because platforms use their own artwork. Copied images can also behave differently from plain text in different applications. If pasting an image does not work, try downloading it and attaching it through the destination application's image picker, where supported.

Emoji Kitchen Hub is an independent website and is not operated by Google. Google's Emoji Kitchen feature and this website's browser tool should not be treated as the same service.
