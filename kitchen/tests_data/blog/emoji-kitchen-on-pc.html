Emoji Kitchen is usually talked about as a phone feature, because Google's version lives inside the Gboard keyboard on Android. But plenty of people want mashups on a computer too, whether for a Discord chat, a slide deck, a school project, or just to browse combinations on a bigger screen.

The good news is that you don't need a phone. This guide shows how to make, save, and share emoji mashups on a Windows PC, a Mac, or a Chromebook, all from a web browser.

Quick note: Emoji Kitchen Hub (emojikitchenhub.com) is an unofficial, fan-made website. It is not run by Google and isn't affiliated with Google, Gboard, or Android. Google's own Emoji Kitchen feature is a separate product, and what it offers can differ from the mixer on this site.

Is there an Emoji Kitchen app for PC?

Not in the way most people expect. Gboard is a mobile keyboard for Android and iPhone, so there's no desktop Gboard that suggests mashups while you type on a computer. Windows and macOS have their own built-in emoji pickers, but those insert standard emoji characters, not mashup stickers.

On a computer, mashups come from the web instead:

  • Google Search. On some browsers and devices, searching "emoji kitchen" on Google shows a mixer on the results page. Google decides where it appears, so it may not show up for everyone.
  • Fan-made web mixers like Emoji Kitchen Hub. These work in any modern desktop browser and let you download results as image files.

How to make an emoji mashup on your computer

Using the mixer on Emoji Kitchen Hub works the same on Windows, Mac, and Chromebook:

  1. Open the Emoji Kitchen Hub homepage in Chrome, Edge, Safari, Firefox, or another up-to-date browser.
  2. Pick a first emoji.
  3. Pick a second emoji.
  4. Look at the preview. If that pair has a mashup, it appears right away.
  5. If nothing shows, swap one emoji. Not every pair has a mashup, since each one is designed artwork rather than an automatic blend.

You can also try the Emoji Maker or the Emoji Generator pages if you want a different layout for browsing pairs.

A bigger screen is handy here. With a mouse and keyboard, it's quicker to scroll through emoji, compare results, and try several pairs in a row than it is on a small phone screen.

How to save a mashup on PC or Mac

Emoji Kitchen results are images, not regular emoji characters. That's the most important thing to know on a computer, because it decides how you save and share them.

To save one:

  1. Use the download button on the mixer when a result is available.
  2. Your browser saves the file to your default downloads folder.
  3. If you can't find it, open your browser's downloads list (in most browsers, press Ctrl + J on Windows and Chromebook, or check the Downloads list in Safari or your browser's menu on Mac).

If downloading doesn't work, you can usually right-click the preview image and choose an option like "Save image as." The exact wording depends on your browser. If you keep running into trouble, see our Emoji Kitchen not working fixes.

How to share mashups from your computer

Because mashups are image files, you share them the same way you'd share a photo:

  • Chat apps on desktop (like Discord, Slack, Messenger, or WhatsApp Desktop): use the attach, upload, or plus button and pick the saved file. Many desktop apps also let you drag the image file straight into the chat window.
  • Email: attach the image like any other file.
  • Documents and slides: use your app's insert image option, or drag the file in.
  • Social media on the web: upload it as an image in a post or comment where images are allowed.

Copy and paste can work in some desktop apps too. If you copy the image and paste it into a chat and nothing happens, that app or text box probably only accepts text. Save the file and attach it instead.

Windows PC tips

  • Built-in emoji panel: Press Windows key + . (period) to open the Windows emoji picker. It inserts standard emoji characters, which are great for typing in sentences, but it doesn't make mashups.
  • Screenshot as a backup: If a download is giving you trouble, Windows key + Shift + S opens the snipping tool so you can capture the preview. A downloaded file is usually cleaner, so use this only as a fallback.
  • Find your files: Downloads normally land in the Downloads folder in File Explorer unless you changed your browser's save location.

For more ways to type emoji on Windows, see our emoji keyboard for PC page.

Mac tips

  • Built-in emoji viewer: Press Control + Command + Space to open the macOS emoji and symbols viewer. Like on Windows, this gives you regular emoji characters, not mashups.
  • Downloads in Safari: Safari saves to your Downloads folder by default. You can open it from Finder or from the Dock.
  • Drag and drop: On a Mac, you can often drag the saved image from Finder right into Messages, Mail, or a desktop chat app.

Chromebook tips

  • Built-in emoji picker: On most Chromebooks, press Search (or Launcher) + Shift + Space to open the emoji picker for standard emoji.
  • Use the browser mixer: The web mixer works in Chrome on a Chromebook just like on any other computer. Downloads go to the Downloads folder in the Files app.
  • Android apps: Some Chromebooks can run Android apps from the Google Play Store. If yours does, you may be able to install Gboard, but whether its mashup suggestions show up on a Chromebook can vary. The browser mixer is the simpler option.

When to use a regular emoji instead

A mashup is a picture, so it won't sit inside a line of text, a username, a file name, or a social bio. For those, you need a standard emoji character. Use your system's emoji picker (shortcuts above) or our online emoji keyboard.

FAQ

Can I use Emoji Kitchen on a PC?

Yes, through a web browser. There's no desktop version of Gboard, but you can make and download mashups with a web mixer like the one on the Emoji Kitchen Hub homepage. Google Search may also show its own mixer on some devices.

Does the Windows emoji keyboard have Emoji Kitchen?

No. The Windows emoji panel (Windows key + period) inserts standard emoji characters. It doesn't combine emoji into mashup stickers.

Can I use Emoji Kitchen on a Mac?

Yes. Open a web mixer in Safari, Chrome, or another browser, pick two emoji, and download the result. The Mac's built-in emoji viewer only offers regular emoji, not mashups.

Does Emoji Kitchen work on a Chromebook?

The browser mixer works in Chrome on a Chromebook. Some Chromebooks can also install Gboard as an Android app, but mashup suggestions there can vary by device.

Why can't I paste a mashup into my chat on my computer?

Mashups are images, so text-only boxes won't accept them. Save the image and use the app's attach or upload button, or drag the file into the chat window.

Is Emoji Kitchen Hub made by Google?

No. Emoji Kitchen Hub is an unofficial, fan-made website. It isn't run by or affiliated with Google. Google's Emoji Kitchen is a separate feature in Gboard and Google Search.
