Emoji Kitchen mashups are a fun fit for Discord. A grinning ghost or a crying cat-heart says a lot in a busy server. But Discord doesn't have Emoji Kitchen built in, and pasting a mashup into the message box doesn't always work the way you'd expect.

This guide shows three ways to use mashups on Discord: sending one as an image, adding it as a custom server emoji, and adding it as a server sticker. It works on Windows, Mac, Android, and iPhone.

Quick note: Emoji Kitchen Hub (emojikitchenhub.com) is an unofficial, fan-made website. It is not run by Google and isn't affiliated with Google, Gboard, Android, or Discord. Google's own Emoji Kitchen feature is a separate product.

Does Discord support Emoji Kitchen?

Not directly. Emoji Kitchen mashups are images, not standard emoji characters, so Discord's emoji picker won't show them and you can't type them with a shortcode.

What you can do is treat a mashup like any other picture:

  • Send it as an image in any channel or DM where you can attach files.
  • Upload it as a custom emoji in a server where you have permission to manage emoji.
  • Upload it as a server sticker in a server where you have permission and sticker slots are available.

All three start the same way: get the mashup as an image file.

Step 1: Make and save your mashup

  1. Open the Emoji Kitchen Hub homepage in your browser.
  2. Pick two emoji.
  3. If that pair has a mashup, it shows in the preview. If not, try a different pair. Not every combination exists, because each mashup is designed artwork.
  4. Use the download button to save the image.

Prefer a different layout for browsing? Try the Emoji Maker or the Emoji Generator.

On Android, you can also get mashups from Gboard. Our Emoji Kitchen on Gboard guide explains how. If a mashup won't save on your phone, see how to save and download Emoji Kitchen stickers.

Option 1: Send a mashup as an image in chat

This is the easiest way, and it works in any channel or DM where you're allowed to upload files.

On desktop (Windows or Mac):

  1. Open the channel or DM.
  2. Click the plus button next to the message box and choose to upload a file, or drag the saved image straight into the chat window.
  3. Add a message if you like, then send.

Making the mashup on a computer first? See how to use Emoji Kitchen on PC, Mac, and Chromebook.

On mobile (Android or iPhone):

  1. Open the channel or DM.
  2. Tap the plus or image button next to the message box.
  3. Pick the mashup from your photos or files, then send.

Can you just paste it? Sometimes. On desktop, copying the image and pasting it into the Discord message box often attaches it. On phones, pasting an image depends on your keyboard and Discord version. If paste does nothing, save the file and attach it instead.

The downside of this method: the mashup shows up as a regular image, not inline with your text like an emoji.

Option 2: Add a mashup as a custom server emoji

If you run a server (or have permission to manage its emoji), you can turn a mashup into a custom emoji. Then everyone in that server can use it in messages and reactions, just like a regular emoji.

  1. Save the mashup as an image file (PNG works well because it keeps the transparent background).
  2. Open Server Settings for your server.
  3. Go to the emoji section.
  4. Choose to upload an emoji and pick your mashup file.
  5. Give it a short, clear name, such as ghost_laugh or cat_heart.

Things to check:

  • Permissions. You need a role with permission to manage the server's emoji. On many servers, only admins and moderators have it.
  • File size and slots. Discord limits how large an emoji file can be and how many custom emoji a server can have. The upload screen tells you the current limits, which can depend on the server's boost level.
  • Readability. Custom emoji display small. Mashups with simple shapes and strong colors are easier to recognize at that size.

Once it's added, type a colon and the emoji's name in that server to use it.

Option 3: Add a mashup as a server sticker

Discord stickers display larger than emoji, which suits detailed mashups.

  1. Open Server Settings.
  2. Go to the stickers section.
  3. Choose to upload a sticker, pick your mashup file, and fill in the name and related emoji Discord asks for.

As with emoji, you need permission to manage the server's stickers, and the number of sticker slots depends on the server. Discord shows the accepted file types and size on the upload screen. If your file is rejected, check those requirements and re-save or resize the image.

Troubleshooting

Pasting does nothing. The message box may not be accepting images from your clipboard. Save the mashup and use the upload or plus button.

I can't find the emoji or sticker settings. Your role probably doesn't have permission. Ask a server admin to add the mashup, or to give you the right role.

The upload is rejected. The file may be too large or in a format Discord doesn't accept for that slot. Check the requirements on the upload screen. Re-downloading the PNG from the mixer usually gives a clean file.

The mashup looks blurry as an emoji. Custom emoji are shown small, so detail gets lost. Try a simpler pair, or use it as a sticker or regular image instead.

The background turned white or black. Some screenshots and paste methods drop transparency. Download the original image file instead of taking a screenshot.

Be a good server citizen

A few quick tips so your mashups stay welcome:

  • Use clear names so people can find the emoji by typing.
  • Don't fill every slot with mashups if your server needs room for other emoji.
  • Follow your server's rules about what can be uploaded.

Want regular emoji instead?

A mashup is a picture, so it won't work in your Discord username, a channel name, or a text-only status. For those, use standard emoji characters from your keyboard or our online emoji keyboard. On a computer, our emoji keyboard for PC page covers built-in shortcuts.

FAQ

Can you use Emoji Kitchen on Discord?

Yes, as images. Save the mashup, then send it as an attachment, or add it to a server as a custom emoji or sticker if you have permission. Discord doesn't include Emoji Kitchen in its own emoji picker.

How do I make an Emoji Kitchen mashup a Discord emoji?

Download the mashup as a PNG, open Server Settings, go to the emoji section, and upload the file. You need permission to manage the server's emoji, and the file has to meet Discord's size limits.

Why can't I paste an Emoji Kitchen sticker into Discord?

Mashups are images, and pasting images depends on your device, keyboard, and Discord version. If paste doesn't work, save the image and attach it with the plus or upload button.

Can I use Emoji Kitchen emoji in my Discord name or status?

No. Mashups are pictures, not text characters, so they can't go in names or text-only fields. Use standard emoji characters there instead.

Do I need Discord Nitro to use mashups?

Not to send them as images or to use custom emoji inside the server where they were added. Discord's paid plan affects things like using a server's custom emoji in other servers. Check Discord's current plan details for specifics.
